# Анализ навигации админ-панели Benehab (эвристическая оценка Нильсена)

## Выявленные проблемы

### 1. **Видимость статуса системы** ✅ ИСПРАВЛЕНО
- **Проблема:** Не было понятно, в каком разделе находится пользователь
- **Решение:** Добавлены хлебные крошки на всех страницах психосемантики

### 2. **Соответствие системы и реального мира** ✅ ИСПРАВЛЕНО
- **Проблема:** Кнопка Back не работала интуитивно — вела на `/admin` вместо логического родителя
- **Решение:** 
  - Back ведет на `/admin?tab=values` для страниц психосемантики
  - Back ведет на `/admin/metrics` для редактора метрики
  - Добавлены подписи "Назад — Психосемантика"

### 3. **Контроль и свобода пользователя** ✅ ИСПРАВЛЕНО
- **Проблема:** При прямом заходе по URL или рефреше Back мог вести в неправильное место
- **Решение:** Навигация основана на логической структуре маршрутов, а не на истории браузера

### 4. **Единообразие и стандарты** ✅ ИСПРАВЛЕНО
- **Проблема:** Разные страницы использовали разные подходы к навигации
- **Решение:** 
  - Единый компонент `BackButton` для всех страниц
  - Единый компонент `Breadcrumbs` для всех страниц
  - Единый формат подписей: "Назад — {Название родителя}"

### 5. **Предотвращение ошибок** ✅ ИСПРАВЛЕНО
- **Проблема:** Технические названия вроде "Менедж концепт" в подписях
- **Решение:** Использованы понятные пользовательские названия: "Психосемантика", "Metrics"

## Структура навигации

### Корневой уровень
- `/admin` — главная страница с вкладками
  - Вкладка "Психосемантика" (`/admin?tab=values`)

### Раздел психосемантики
- `/admin/concepts` ← Back: `/admin?tab=values`
- `/admin/ranks` ← Back: `/admin?tab=values`
- `/admin/metrics` ← Back: `/admin?tab=values`
- `/admin/metrics/[metricId]` ← Back: `/admin/metrics`
- `/admin/settings` ← Back: `/admin?tab=values`
- `/admin/debug` ← Back: `/admin?tab=values`

## Хлебные крошки

Все страницы психосемантики теперь имеют хлебные крошки:
- **Админ панель** → **Психосемантика** → **{Текущая страница}**
- Кликабельные элементы ведут на соответствующие страницы

## Рекомендации для будущего

1. **Добавить историю навигации:** Использовать `router.back()` как fallback, если нет логического родителя
2. **Добавить клавиатурные сокращения:** `Cmd/Ctrl + ←` для Back
3. **Добавить индикацию активной вкладки** в URL при прямом заходе
4. **Единообразие для других разделов:** Применить те же принципы к "Отношение к болезни" и "Психотипы"
