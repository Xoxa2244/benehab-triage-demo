# Benehab - Персональный помощник по здоровью

## Описание проекта

Benehab - это веб-приложение для персональной помощи в вопросах здоровья, использующее ИИ-ассистента "Татьяна" для персонализированного общения с пациентами.

## Функциональность

### ✅ Завершено:
- **Этап 1**: Базовая структура и страница назначений
- **Этап 2**: Push-уведомления и Service Worker
- **Этап 3**: Интеграция с Татьяной и чатом

### 🔄 В разработке:
- **Этап 4**: Cron-джоба и логика расписания

## Технологии

- Next.js 13.5.6
- React 18.2.0
- TailwindCSS
- OpenAI GPT-4o-mini
- Web Push Notifications
- Service Workers

## Установка и запуск

```bash
npm install
npm run dev
```

## Структура проекта

- `/pages` - страницы приложения
- `/components` - React компоненты
- `/lib` - утилиты и логика
- `/data` - данные опросов и конфигурация
- `/public` - статические файлы
